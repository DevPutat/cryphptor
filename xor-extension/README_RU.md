# Cryphptor XOR Extension для PHP 8.4

PHP-расширение для XOR-шифрования PHP-файлов с прозрачной расшифровкой при выполнении.

> ⚠️ **Предупреждение**: XOR-шифрование не является надёжным способом защиты. Используйте только для обфускации кода.

## Возможности

- C-расширение PHP с функциями XOR-шифрования/расшифрования
- Прозрачная расшифровка зашифрованных PHP-файлов при выполнении
- Docker-образ для развёртывания
- Шифрование всех PHP-файлов в проекте одной командой

## Быстрый старт

### Сборка Docker-образа

```bash
docker build -t cryphptor-xor-8.4:latest -f Dockerfile.php8.4 .
```

### Шифрование PHP-файлов

```bash
docker run --rm \
  -v /путь/к/проекту:/data \
  cryphptor-xor-8.4:latest \
  encrypt-php "ваш_секретный_ключ" /data
```

### Запуск зашифрованного приложения

```bash
docker run --rm \
  -e XOR_DECRYPT_KEY="ваш_секретный_ключ" \
  -v /путь/к/зашифрованному/проекту:/var/www \
  cryphptor-xor-8.4:latest \
  php artisan serve --host=0.0.0.0 --port=8000
```

## Как это работает

1. **Шифрование**: Скрипт `encrypt.php` проходит по всем `.php` файлам и шифрует их XOR-ключом
2. **Расшифровка**: При запуске контейнера с `XOR_DECRYPT_KEY`, все PHP-файлы расшифровываются на лету при включении через `require`/`include`
3. **Прозрачность**: Никаких изменений в код приложения вносить не нужно!

## Переменные окружения

- `XOR_DECRYPT_KEY` - ключ расшифровки (обязательно для зашифрованных приложений)
- `APP_DIR` - директория приложения (по умолчанию: `/var/www`)

## Пример: Laravel приложение

### 1. Создайте образ

```bash
docker build -t cryphptor-xor-8.4:latest -f Dockerfile.php8.4 .
```

### 2. Зашифруйте проект

```bash
# Создайте резервную копию!
cp -r /var/www/laravel /var/www/laravel.backup

# Зашифруйте все PHP-файлы
docker run --rm \
  -v /var/www/laravel:/data \
  cryphptor-xor-8.4:latest \
  encrypt-php "my_super_secret_key_123" /data
```

### 3. Запустите

```bash
docker run --rm \
  -e XOR_DECRYPT_KEY="my_super_secret_key_123" \
  -v /var/www/laravel:/var/www \
  -p 8000:8000 \
  cryphptor-xor-8.4:latest \
  php artisan serve --host=0.0.0.0 --port=8000
```

Laravel запустится без каких-либо изменений в коде!

```
│   ├── xor_decrypt.c       # Основной код расширения
│   ├── config.m4           # Конфигурация сборки
│   └── ...
├── xor_autoloader.php      # PHP-обёртка для расшифровки
├── encrypt.php             # Скрипт шифрования
├── Dockerfile.php8.4       # Dockerfile
└── docker-entrypoint.sh    # Скрипт запуска контейнера
```

## Важные замечания по безопасности

1. **XOR не является шифрованием**: Ключ можно подобрать анализом частот
2. **Ключ в памяти**: Ключ должен быть доступен при выполнении, его можно извлечь
3. **Обфускация, не защита**: Это затрудняет чтение кода, но не делает его недоступным
4. **Резервные копии**: Всегда сохраняйте оригинальные файлы до шифрования!

## Сборка из исходников

### Требования

- PHP 8.4 с phpize
- Компилятор GCC

### Сборка расширения

```bash
cd php.8.4/xor_decrypt
phpize
./configure
make
make install
```

### Подключение расширения

Добавьте в `php.ini`:
```ini
extension=xor_decrypt.so
```
